# 峡谷新手手册 · 本地站点

面向低分段上分玩家的王者荣耀资料站。纯静态 HTML/CSS/JS，双击 `index.html` 就能看，不需要装任何东西、也不需要联网（英雄头像已本地化）。

## 怎么打开

```bash
open index.html          # macOS
# 或者用任意静态服务器：
python3 -m http.server 8000
```

## 内容从哪来

- **技能名称 / 冷却 / 消耗 / 技能描述 / 定位 / 分路**：王者荣耀官网英雄资料页，抓取于 2026-10-28，133 位英雄、542 条技能。
- **一句话、技能人话版、连招、对线/团战、出装、铭文**：本站撰写，不是官方表述。
- **遇到他怎么办（3-4 条）+ 克制出装（3 件，含俗称 / 为什么出 / 谁来出）**：133 位英雄全部覆盖，本站撰写。
- **装备属性**：只写“给什么”，不写具体数值；数值随版本浮动，以游戏内为准。

> 官网有两套英雄页地址（`/173.shtml` 旧版、`/liyuanfang.shtml` 新版），新手册用的是新版。若发现数值与游戏内不符，以游戏内为准。

## 站点功能

- 全站搜索（`⌘K` / `Ctrl+K`）：支持别名和拼音（“猴子”→孙悟空，“奶妈”→蔡文姬）
- 英雄筛选：定位 / 分路 / 只看精编 + 站内搜索
- 英雄详情：速览 → 技能人话版（可展开官方原文）→ 打法 → 应对 → 出装 → 克制
- **悬浮导航**：左下角按钮唤出抽屉，含「返回上一页」「本页目录」「去别的页面」，手机上从底部弹出
- **对局速查**：英雄页右下角一键切换，只留最关键的应对 + 该出的装备，一屏看完
- **克制出装**：每件装备写清「全名 + 俗称 + 为什么出 + 谁来出」，点进去是装备详情页；搜索俗称（反甲、制裁、魔女）也能直接找到
- 装备决策助手：勾选对面阵容特点，推荐该补的装备
- 选英雄小问答：两个问题，推荐两个能直接上手的英雄
- 基础课阅读进度条、术语即时搜索

## 其他部署方式

纯静态，扔到哪里都能跑：

- 国内最快：腾讯云 COS + CDN（需实名 + 少量费用）
- 国内免折腾：飞书妙搭（`lark-cli apps +html-publish`，需一次授权）
- 海外：Vercel / Cloudflare Pages / GitHub Pages

上传整个 `site/` 目录即可，入口是 `index.html`。

## 已知取舍

- 不做实时胜率/出场率：官方不公开，营地接口封闭，硬编数据不可信。
- 装备不写具体数值：版本两周一小调，写死反而容易误导。
- 出装是“决策 + 示例”，不是“唯一解”。
- 新英雄（2024 年后上线）的强弱判断偏保守，以官方机制为准。
